# ES6 Classes

JavaScript exercises covering class constructors, getters and setters,
static methods, inheritance, and symbols.

## Environment

Ubuntu 20.04 LTS and Node.js 20.x.

## Setup

Use the package.json, babel.config.js, and .eslintrc.js supplied
on the Holberton project page.

Install the project dependencies with npm install.
Do not commit node_modules.
