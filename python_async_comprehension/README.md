# Python - Async Comprehension

This project covers asynchronous generators and comprehensions in Python.

## Learning Objectives

- Write asynchronous generators
- Use async comprehensions
- Type-annotate generators
- Run asynchronous operations concurrently
- Measure the runtime of parallel coroutines

## Files

- `0-async_generator.py` - Defines an asynchronous generator that yields random numbers
- `1-async_comprehension.py` - Collects values using an async comprehension
- `2-measure_runtime.py` - Measures the runtime of four parallel async comprehensions
